# FERRY  CAPACITY UTILIZATION & OPERATIONAL EFFICIENCY ANALYTICAL SYSTEM

## Project Overview
This project analyzes the Toronto Island Ferry Tickets dataset to measure ferry capacity utilization and operational efficiency. It helps identify peak demand periods, idle capacity, and operational trends using data analytics and visualization.

## Objectives
- Analyze ferry ticket sales and redemption data.
- Measure capacity utilization.
- Identify congestion and idle periods.
- Generate operational insights using KPIs.
- Build an interactive Streamlit dashboard.

## Dataset
- Toronto Island Ferry Tickets Dataset (2015–2025)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- Jupyter Notebook

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- KPI Calculation
- Capacity Utilization Analysis
- Interactive Streamlit Dashboard

## Project Files
- app.py
- ferry_analysis.ipynb
- Final_Ferry_Analysis.csv
- Research_paper.pdf
- EXECUTIVE_SUMMARY.pdf

## How to Run
1. Install the required libraries.
2. Open the project folder.
3. Run:
   
   python -m streamlit run app.py
   
4. Open the local URL displayed in the terminal.

## Conclusion
This project provides insights into ferry operational efficiency and supports better scheduling, resource allocation, and decision-making using data analytics.
